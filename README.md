# LindaLuna site

Static site for SmartHeal LindaLuna and Luna's Parcours.

## Publish on GitHub Pages
1. Create a public repository (e.g. `lindaluna`) and upload everything in this folder.
2. Settings > Pages > Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The site appears at `https://<your-user>.github.io/lindaluna/` after a minute.

## Edit links
At the bottom of `index.html`, in `const LINKS`, replace the PayPal and CurseForge URLs.

## Screenshots
Put images in `assets/` and replace each `<div class="frame">Screenshot coming soon</div>` with
`<img src="assets/your-file.webp" alt="...">`.
